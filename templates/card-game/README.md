# {{projectName}}

Memory-match card game with flip animations & a move counter. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command | Description |
| --- | --- |
| `bun run dev` | Start the dev server (http://localhost:5173) |
| `bun run build` | Production build into dist/ |
| `bun run preview` | Serve the production build |
| `bun run typecheck` | Type-check with tsc |

## Controls

| Input | Action |
| --- | --- |
| Mouse click | Flip a card (two at a time, to find a pair) |

Match all six unicode-symbol pairs: a match keeps both cards face-up with a
little pop, a mismatch flips them back down after a beat. Every two-card
attempt counts as a move - fewer moves, better run. Clear the board and click
anywhere to shuffle a fresh deal.

## Customize

- `src/config.ts` — canvas size, colors, symbols and layout/timing tunables
- `src/scenes/GameScene.ts` — the gameplay code (dealing, flipping, matching, win screen)
