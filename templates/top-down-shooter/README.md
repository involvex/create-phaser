# {{projectName}}

WASD movement, mouse aim & escalating enemy waves. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command             | Description                                  |
| ------------------- | -------------------------------------------- |
| `bun run dev`       | Start the dev server (http://localhost:5173) |
| `bun run build`     | Production build into dist/                  |
| `bun run preview`   | Serve the production build                   |
| `bun run typecheck` | Type-check with tsc                          |

## Controls

| Input                                | Action                                  |
| ------------------------------------ | --------------------------------------- |
| W / A / S / D                        | Move around the walled arena            |
| Mouse                                | Aim                                     |
| Hold Space or hold left mouse button | Fire toward the pointer (on a cooldown) |
| R or click                           | Restart on the Game Over screen         |

Enemies spawn at the arena edges in waves that keep growing (and moving faster); dodge them and shoot back. Touching an enemy costs one HP — you flash briefly invulnerable after a hit. Survive as long as you can.

## Customize

- `src/config.ts` — canvas size, colors, gameplay tunables
- `src/scenes/GameScene.ts` — the gameplay code
