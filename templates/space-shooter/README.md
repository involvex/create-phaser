# {{projectName}}

Shmup with waves of enemies, bullets & particle explosions. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command | Description |
| --- | --- |
| `bun run dev` | Start the dev server (http://localhost:5173) |
| `bun run build` | Production build into dist/ |
| `bun run preview` | Serve the production build |
| `bun run typecheck` | Type-check with tsc |

## Controls

| Input | Action |
| --- | --- |
| Arrow keys or WASD | Move the ship (clamped to the screen) |
| Space (hold) | Fire — auto-repeats on a short cooldown |
| R | Restart on the Game Over screen |

Enemies sink toward the bottom in zig-zagging waves. Each enemy that slips past you costs one life (you start with 3). Clear a wave and the next one is bigger. Shooting down enemies builds your score.

## Customize

- `src/config.ts` — canvas size, colors, gameplay tunables
- `src/scenes/GameScene.ts` — the gameplay code
