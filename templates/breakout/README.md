# {{projectName}}

Classic brick-breaker with paddle-angle physics & lives. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command | Description |
| --- | --- |
| `bun run dev` | Start the dev server (http://localhost:5173) |
| `bun run build` | Production build into dist/ |
| `bun run preview` | Serve the production build |
| `bun run typecheck` | Type-check with tsc |

## Controls

| Input | Action |
| --- | --- |
| Mouse move | Steer the paddle |
| Left / Right arrows or A / D | Keyboard steering |
| Click or Space | Launch the ball off the paddle |
| R or click | Restart from the Game Over / You Win screen |

Clear all 50 bricks (5 colored rows × 10 columns) to win. Where the ball lands on the paddle changes its outgoing angle — center hits go straight up, edge hits deflect wide. You start with 3 lives; every ball that falls past the bottom edge costs one.

## Customize

- `src/config.ts` — canvas size, colors, gameplay tunables
- `src/scenes/GameScene.ts` — the gameplay code
