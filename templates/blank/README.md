# {{projectName}}

Minimal starter - Boot + Game scene skeleton to build on. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command | Description |
| --- | --- |
| `bun run dev` | Start the dev server (http://localhost:5173) |
| `bun run build` | Production build into dist/ |
| `bun run preview` | Serve the production build |
| `bun run typecheck` | Type-check with tsc |

## Controls

| Input | Action |
| --- | --- |
| `Space` | Toggle the sample text block |

That is all there is on purpose - `src/scenes/GameScene.ts` is a deliberately
small skeleton: a headline, one animated square and a key toggle. Everything
below the `YOUR GAME GOES HERE` banner in `GameScene.create()` is yours to
delete and rebuild.

## Customize

- `src/config.ts` — canvas size, colors, gameplay tunables
- `src/scenes/BootScene.ts` — generate reusable procedural textures here
- `src/scenes/GameScene.ts` — the gameplay code
