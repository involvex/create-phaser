# {{projectName}}

Side-scroller with jumping, platforms, coins & a follow camera. Generated by [@involvex/create-phaser](https://github.com/involvex/create-phaser).

## Getting started

Install dependencies with your package manager (`bun install` or `npm install`), then:

| Command             | Description                                  |
| ------------------- | -------------------------------------------- |
| `bun run dev`       | Start the dev server (http://localhost:5173) |
| `bun run build`     | Production build into dist/                  |
| `bun run preview`   | Serve the production build                   |
| `bun run typecheck` | Type-check with tsc                          |

## Controls

| Input               | Action                               |
| ------------------- | ------------------------------------ |
| `←` `→` or `A` `D`  | Move left / right                    |
| `W` / `↑` / `Space` | Jump (only while standing on ground) |
| `R`                 | Restart the level                    |

Collect coins for score, ride the follow camera across a 1920px-wide world,
and don't drop into the pits - falling off the bottom shakes the screen and
restarts the run. The purple patroller is scenic for now: add a player/enemy
overlap in `GameScene` to make it dangerous.

## Customize

- `src/config.ts` — canvas size, colors, gameplay tunables (level layout, jump strength, ...)
- `src/scenes/BootScene.ts` — generates every procedural texture
- `src/scenes/GameScene.ts` — the gameplay code
